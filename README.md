# Atlas do Folclore — demonstração

Protótipo de um mapa interativo para explorar lendas e mitos, no estilo de um atlas antigo.
Nesta versão, só o Brasil está mapeado: mundo › Brasil › região › estado › ficha da lenda.

A demonstração é um único arquivo (`index.html`) com código, mapa e fontes embutidos.
Não faz pedidos a outros servidores e funciona sem instalar nada.

Os textos das lendas são provisórios. Os personagens 3D ainda estão em produção.
